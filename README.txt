VEE’S CREATIVES PORTFOLIO WEBSITE

1. Extract this ZIP file.
2. Open the Chioma_Portfolio_Website folder.
3. Double-click index.html to preview locally. Keep the assets folder beside index.html.
4. The CV PDF is included in this folder and is linked from the cover page.
5. Preview design buttons open the image modal. Owner edit mode can remove cards from the current preview only; it is not secure authentication and does not update a published website automatically.
6. To publish, upload the extracted website folder/contents to a static hosting service, following that service’s instructions. Re-upload the updated files after any future changes.
